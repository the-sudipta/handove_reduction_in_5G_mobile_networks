Ensemble-DQN Replication Check
Replication check · Part A · authors' method, unchanged

Does the published code reproduce the paper's results?

Jalili Sanjarani, Elmi Sola, Hasanpour, Neghabi. Handover reduction in 5G mobile networks using ensemble learning method. Scientific Reports, 2026. doi:10.1038/s41598-026-73269-1

Yes, for the simulated experiments. Running the authors' own code without any change reproduces Table 4 and the headline percentages. One condition applies: the result depends on the random seed. 2 of the 11 seeds we tried, including the code's default seed 42, give a failed DQN training run.

Method of the replication

Nothing in the authors' method was re-written or corrected. Our script only calls their functions in the order their own main() does.

  1. Authors' codeOfficial repository mjs19971997/ensemble-dqn-5g-handover, commit b61e399, imported unmodified.
  2. Authors' dataScale1x/2x/3x datasets regenerated with their generate_data.py, seed 42 (20/40/60 cells, 10,000/20,000/30,000 rows).
  3. Authors' pipeline70/30 split, K-Means + PCA + Decision Tree, 3-epoch DQN pre-training, margin δ = 0.2, A3 / LSTM / RL baselines.
  4. Repetitions30 Monte-Carlo runs per point, as in the paper, repeated for experiment seeds 0–9 and 42. The tables show the median over seeds 0–9.
